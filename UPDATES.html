B3Fixed

Navigation is no longer blocked for seconds.

PageReadySignal's effect is now keyed on pathname. In the root layout with [] deps it fired exactly once on first load, so the transition overlay never received its dismiss event again and fell through to blind fallback timers on every subsequent navigation. Also removed the duplicate <DynamicCosmic /> from the homepage — two full-screen rAF loops where the second painted over the first.

B6Fixed & verified

Full metadata and structured-data surface.

Rewrote the root metadata with metadataBase, a title template, Open Graph, Twitter card, canonical, robots directives and icons. Added a Person + WebSite JSON-LD graph. Deleted the dead head.tsx. All URLs derive from a single src/lib/site.ts so there is one place to set the domain.

I did not split the nine routes into server wrappers for per-page metadata — see §05.

B5Fixed

prefers-reduced-motion is now honoured.

Added a global CSS backstop covering every animation, transition and smooth scroll. In the canvas, the rAF loop and the mouse-parallax listener are skipped entirely and a single static frame is painted instead. Also capped DPR (uncapped before — a 3× phone allocated 9× the pixels), hoisted the per-frame gradient allocation out of the tick, and capped star alpha so text contrast is bounded.

B2Partially fixed

Tailwind config resolved — token migration deferred.

The dead tailwind.config.js is no longer misleading: tailwind-merge was removed and the config's only real content was the unshipped cyan override. The full @theme{} token migration (collapsing 18 cyans, 42 near-blacks, 23 durations) is Phase 4 work and is not done — see §05.

The GitHub sync uses the build-time approach from the audit rather than runtime ISR: the site stays fully static, the rate limit is a non-issue at one authenticated run per day, and every content change arrives as a reviewable diff. Opt in by adding the topic portfolio to a repository.

One secret to add before the sync runsCreate a repository secret PORTFOLIO_GH_PAT with public_repo and read:user scopes. The read:user scope is required because pinned repositories are a user-level GraphQL field that the default GITHUB_TOKEN cannot see. Until then, sync-projects.yml will fail; nothing else depends on it.

The freshness script was validated against real data. It correctly flags AI-102 as 25 months past issue, and correctly does not flag AI-900 — Microsoft Fundamentals certifications never expire, only role-based ones do.

Also added: .nvmrc, grouped Dependabot config, packageManager and engines pins, security headers and avif in next.config.ts, removal of the broken next export script, and a rewritten README replacing the create-next-app boilerplate.

05

Deliberately Left Open

3 items

These were not attempted, for reasons given. Nothing here blocks the site from working.

O1Needs your decision

The AI-102 certification claim.

/certificates displays Microsoft Certified: Azure AI Engineer Associate (AI-102), issued Jun 30 2024, presented as current. Microsoft role-based certifications expire twelve months after issue unless renewed — this one is 25 months old.

I did not change it. If you renewed it, the displayed issue date should be updated to the renewal date and nothing is wrong. If you did not, a live portfolio is currently asserting a lapsed credential to recruiters. Either way this is a factual claim about you, so it is yours to settle — the weekly freshness job will keep raising it until the data changes.

AI-900 is a Fundamentals certification and never expires. It is correctly not flagged.

O2Deferred — Phase 4

The design-system consolidation.

Not attempted: 18 cyans, 42 near-blacks, 35 shadows, 23 animation durations, 211 inline style objects, 20 button recipes and 25 card recipes remain. No typeface is loaded — the site still renders in the system default. The 189 borders and surfaces at 2–8% opacity are still effectively invisible.

This is the largest remaining body of work and it is almost entirely visual. Doing it properly means a @theme{} token block plus extracting Surface, Button and Modal — those three alone replace about 90 bespoke recipes. It deserves its own pass with you reviewing the result, rather than being folded silently into a remediation commit. Loading a typeface is the single highest-value change in it.

O3Deferred

Per-page metadata and the lint backlog.

All nine pages remain "use client", so they still share one title and description. Fixing it means splitting each route into a thin Server Component wrapper — roughly ten lines per route, low risk, but nine files of churn on top of an already large change. The root metadata, sitemap and JSON-LD deliver most of the SEO benefit now; per-page titles are the remaining increment.

Lint sits at 78 errors / 27 warnings, down from 90/33 only as a side-effect of deleting dead files. The bulk is @typescript-eslint/no-explicit-any (concentrated in professional-ai) and unused vars. CI reports lint with continue-on-error so the backlog is visible without blocking; remove that flag once it is cleared.

Also still open from the audit: the six modals lack focus traps and body-scroll locking, /skills autoplays a video with no pause control, three carousels remain clipped or mispositioned on mobile, and /professional vs /professional-ai are still two pages maintaining the same résumé.
